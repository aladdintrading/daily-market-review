개인정보처리방침

최종 수정일: 2026-09-13

1. 이 도구의 성격

DailyMarketReview는 운영자 개인이 본인 소유의 YouTube 채널을 운영하기 위해 사용하는 내부 자동화 도구입니다. 일반 사용자에게 제공되는 서비스가 아니며, 제3자로부터 회원가입을 받거나 개인 계정 정보를 수집하지 않습니다.

2. 수집 및 처리하는 정보

이 도구는 다음 정보만을 처리합니다.

  • 공개된 국내 증시 지수·업종·투자자 매매동향 데이터 (금융 정보 제공처를 통해 수집)
  • 공개된 뉴스 기사 (제목, 본문 일부, 발행 시각 등)
  • 운영자 본인의 Google 계정에 대한 YouTube Data API OAuth 접근 권한 (동영상 업로드, 메타데이터 설정, 썸네일 등록 목적)

이 도구는 최종 사용자(시청자)의 개인정보를 수집하지 않습니다. YouTube 영상 시청자로부터 별도의 데이터를 수집하거나 추적하지 않습니다.

3. 정보의 사용 목적

수집한 시장 데이터와 뉴스는 리뷰 영상 콘텐츠 제작에만 사용되며, 운영자 본인 채널에 업로드하는 목적 외에 다른 용도로 사용되거나 제3자에게 제공되지 않습니다.

4. YouTube API 서비스 및 Google 정책

이 도구는 YouTube API 서비스를 사용하며, 이 API 서비스 사용은 YouTube 서비스 약관의 적용을 받습니다. 이 도구를 통해 처리되는 Google 사용자 데이터의 취급에는 Google 개인정보처리방침이 함께 적용됩니다.

5. 데이터 보관 및 삭제

OAuth 인증 토큰은 운영자 본인의 서버 환경에만 저장되며 제3자와 공유되지 않습니다. 수집된 뉴스·시장 데이터는 영상 제작 목적으로만 단기간 보관되며, 필요 시 운영자가 직접 삭제할 수 있습니다.
