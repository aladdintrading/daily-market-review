DailyMarketReview

매일 장 마감 후 국내 증시 데이터와 주요 뉴스를 수집·분석하여 리뷰 영상을 자동으로 생성하고, 운영자 본인 소유의 YouTube 채널에 업로드하는 개인용 자동화 도구입니다.

개인 프로젝트 비상업적 · 소규모 운영

무엇을 하나요

지수·업종·투자자 매매동향 등 공개된 시장 데이터를 수집해 음성 나레이션이 포함된 영상으로 구성하고, YouTube Data API를 통해 운영자 본인 채널에 업로드합니다. 하루 2~3개, 각 영상은 약 15분 분량입니다.

누구를 위한 도구인가요

일반 사용자에게 서비스를 제공하는 제품이 아니라, 운영자 개인이 본인 채널 운영을 위해 사용하는 내부 자동화 도구입니다. 제3자 사용자 계정을 관리하거나 제3자 데이터를 수집하지 않습니다.

YouTube API 사용 범위

업로드 영상의 메타데이터(제목·설명·태그) 설정, 맞춤 썸네일 등록, 재생목록 등록 등 운영자 본인 채널의 동영상 관리 기능만 사용합니다.
